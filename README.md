# pietrochierico.github.io

Personal academic website of **Pietro Chierico**, PhD student in Biomedical Engineering
(Universitat Politècnica de València). Built with [Quarto](https://quarto.org/), published via
GitHub Pages from the `docs/` folder.

Live site: <https://pietrochierico.github.io>

## Structure

- `index.qmd` — home page (bio, affiliations, awards, latest)
- `projects.qmd` — research lines, selected publications, open-source & teaching resources
- `cv.qmd`, `contact.qmd` — CV and contact
- `_quarto.yml` — site configuration and navigation
- `files/` — profile photo, award image, institution logos
- `docs/` — rendered site (do not edit by hand; regenerated by `quarto render`)

## Update the site

```bash
quarto preview      # local preview with live reload
# edit the .qmd files, then:
quarto render        # rebuilds docs/
git add .
git commit -m "..."
git push
```

GitHub Pages serves whatever is committed in `docs/`, so `quarto render` must be run (and its
output committed) before pushing a content change.
